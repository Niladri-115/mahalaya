================================================================================
AGOMONI - AKASHVANI LIVE STREAM SYSTEM
================================================================================

This application connects directly to the official Akashvani / AIR Bangla
live streaming broadcast service:

  AKASHVANI LIVE -> AIR BANGLA -> WHATEVER IS ON AIR

No local "mahalaya.mp3" file is required or used.

On Mahalaya morning, when Akashvani broadcasts Mahishasuramardini,
the website carries that broadcast live directly from the official
Akashvani / Prasar Bharati servers.

To configure or update the live streaming URL, see:
  js/akashiVani.js

================================================================================
